# Réflexes Cabinet – Réunion · iPhone

Version PWA optimisée pour iPhone : icônes Apple, mode autonome plein écran, zone sûre iPhone, écran de lancement, cache hors connexion et aide d'installation intégrée.

## Installation

Il faut d'abord publier le contenu de ce dossier sur une adresse HTTPS (GitHub Pages, Netlify, Cloudflare Pages, etc.).

Puis sur l'iPhone :

1. Ouvrir l'adresse dans **Safari**.
2. **Partager**.
3. **Sur l'écran d'accueil**.
4. Activer **Ouvrir comme app web**.
5. **Ajouter**.

L'application s'ouvrira ensuite depuis son icône comme une app indépendante.

## Pourquoi pas un .ipa ?

Une application iOS native installable directement nécessite une signature Apple valide et un mécanisme de distribution autorisé (TestFlight, App Store ou provisioning approprié). Ce package est donc volontairement une PWA installable sans compilation Xcode.
